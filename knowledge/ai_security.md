# AI / RAG security notes

## RAG risks

В RAG модель отвечает по найденному контексту. Риски: prompt injection в документах,
утечка чувствительных чанков в ответ, poisoning базы знаний.

## MCP / agents

Агенты с инструментами опаснее «голого» чата: tool calling может дернуть внешние API
или файлы. Нужны allowlist инструментов, human-in-the-loop на опасных действиях,
логирование вызовов.

## Practical controls

- резать секреты из индексируемых доков
- разделять корпуса по доступу
- не отдавать сырой retrieval в прод без фильтров
- для CI/безопасности AI чаще хватает policy + eval harness, а не «ещё одна модель»
